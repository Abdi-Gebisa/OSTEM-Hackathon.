# OSTEM Submission Checklist

## Before uploading
- [ ] Confirm the hackathon portal accepts a ZIP or provide the GitHub repository URL if required.
- [ ] Upload the extracted project contents to the repository root (not an extra nested parent folder).
- [ ] Publish and open the deployed site on an Android phone.
- [ ] Test at least Projectile Motion, Newton's Second Law and Snell's Law.
- [ ] Test numeric input, slider sync, Run/Pause/Step/Reset, graph, formula/theory and CSV export.
- [ ] Test Physics Tutor, calculator, report download, EUEE questions and Learning Challenges.
- [ ] Load the site once online, then switch to airplane mode and test cached assets.
- [ ] Record a 2–3 minute demo showing real working features.
- [ ] Do not claim a live generative AI model or confirmed Solana transaction.
- [ ] Keep a copy of the exact submitted ZIP and final Git commit.

## Submission description
OSTEM is an offline-capable virtual Physics laboratory for Ethiopian secondary-school learners. It lets students control experiment variables, observe visual simulations, inspect live measurements and graphs, use a Physics study tutor, practise EUEE-style questions and complete learning challenges. Its local achievement hash demonstrates a privacy-conscious proof concept; Solana Devnet recording remains a future integration and is not claimed as live in this build.
